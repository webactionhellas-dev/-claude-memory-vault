**Source template**: a Next.js static export that bails to client-side rendering and draws ALL products from one webpack data module `3245` (image map `t`, products array `l`, derived exports `o`=featured/`c`=trending/`d`=new-arrivals/`g`=drops). Dark "ink" theme (`--accent:#00e5ff`, `--bg:#050505`), Tailwind, framer-motion 3D-tilt cards, Lenis smooth-scroll, glassmorphism (`.glass`/`.glass-strong`).
