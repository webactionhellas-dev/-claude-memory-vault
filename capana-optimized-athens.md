**CRITICAL RSC gotcha (caused a fully black/blank page; fixed 2026-07-01):** the JSON-LD in js/017.js is a React Server Components *length-prefixed* flight chunk. The tail of js/016.js ends with `...2:T<hex>,"])` where `<hex>` is the **UTF-8 byte length** of the JSON-LD payload in js/017.js. When the JSON-LD was edited from the Italian original to Athens, the payload shrank (1064→929 bytes) but the prefix stayed `2:T428,` (1064). React's flight reader then over-reads 135 bytes into the next chunk, throws **"Uncaught Error: Connection closed" (from js/003.js, the react-server-dom runtime)**, and *wipes the entire SSR body* → black screen, `__next_f` ends length-0. Fix: set the prefix to the real byte count → `2:T3a1,` (0x3a1=929). Any future edit to js/017.js's JSON-LD MUST update this prefix. A reusable fixer that recomputes the prefix from js/017.js and rewrites js/016.js lives at `C:\Users\nospa\Desktop\capana\fix_flightlen.py` (run: `python fix_flightlen.py <folder>`).
